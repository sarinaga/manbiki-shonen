# manbiki-shonen
1979年にPET 2001で作られた世界初のステルスゲームを現代風のWebブラウザゲームにしたもの。

ゲームは[GitHub Pages](https://sarinaga.github.io/manbiki-shonen/)ないし[itch.io](https://sarinaga.itch.io/manbiki-shonen)で遊べるようになっています。

## ゲームの目的

- コンビニ店内にある8つの棚から商品を盗んでいきます。
- すべての商品を盗むと出口が「OPEN」します。出口から脱出すれば「ROUND CLEAR」です。

## 操作方法

[ChatGPTによる検閲により犯罪表現を消されてしまったインストラクションカード](./Instruction_card.png)([英語版](./Instruction_card.eng.png))に、ゲームの目的や操作方法などが書かれています。本当はこのREADME.mdに書かれている文面にしたかったのですが。

### キーボード

- 矢印キー または WASD：移動
- ENTER または SPACE：ゲーム開始 / 次ROUND
- M：SOUND ON / OFF
- P：PAUSE
- ESC：タイトルへ戻る（GAME OVER / PAUSE時）

### ゲームコントローラー

- 方向入力：移動
- 第1ボタン：ゲーム開始 / 次ROUND / リトライ

## 商品の取り方

- 商品のある棚に向かって移動し続けると、商品を盗みます。
- 商品を盗むには一定時間が必要です。商品を盗んでいる間は「STEAL」インジケーターが表示されます。

## 店員について

- 店員は店内を監視し、万引きしたプレイヤーを見つけようとしています。
- 万引きしたところを店員に見つかったら最後、もう逃げることはできません。「GAME OVER」です。
- 店員に見つからないよう、棚に隠れながら商品を盗んでいきましょう。
- ROUNDが進むと店員の動きなどが変化し、難易度が上がっていきます。

## スコア

- 商品を1つ盗むごとに10点獲得します。
- ROUND CLEAR時には、残り時間に応じて「TIME BONUS」が加算されます。

## デバッグ機能

このゲームにはデバッグ機能があります。操作方法は以下のとおりです。

- F1：デバッグモード ON / OFF
- TAB：変更するパラメータを選択
  - 変更できるパラメータ
    - TIME：残り時間
    - PLAYER_SPEED：プレイヤーの移動速度
    - STEAL_TIME：商品を盗むのに必要な時間
    - GUARD_SPEED：男性店員の移動速度
    - FEMALE_GUARD_SPEED：女性店員の移動速度
    - VIEW_ANGLE：店員の下方向視野角
- `[`：選択中のパラメータの値を減らす
- `]`：選択中のパラメータの値を増やす
- I：無敵モード ON / OFF
- T：全商品を取得した状態にする
- C：HIGH SCOREを初期値にリセット
- H：壁と棚の当たり判定表示 ON / OFF

デバッグモードでは、店員の視界・検出範囲も画面上に表示されます。また、PAUSE中でもデバッグ操作を行えます。

なお、デバッグモードを一度でも使用したゲームでは、HIGH SCOREは更新されません。デバッグモードをOFFに戻しても、そのゲーム中はHIGH SCORE更新対象には戻りません。リトライして新しいゲームを開始すると、デバッグモードの状態に応じて改めて判定されます。

## ゲーム開発のいきさつ

ChatGPTによるソースコード生成能力の力量を測るため、また自身のAIによるコード生成の習作として、[マイコンBASICマガジン](https://www.aabmg.com/)に載っていたようなゲームを、プロンプト入力だけで作成できるかどうか試してみたのがきっかけです。

思いのほかゲームの原型が簡単にできたため、そこから本格的に作り込んでみようと相成りました。原型から仕上げまではかなりの悪戦苦闘をしましたが、わずか5日程度で世の中にお見せできる内容が出来上がったことを記念して、ここに公開することにしました。

ごく一部でフリー素材を使ったり、手作業で修正を行ったりした箇所はありますが、スプライト生成・背景・タイトル画面・効果音なども含め、ほとんどすべてがChatGPTの出力結果によって構成されています。

ほとんどすべてをAIで作れてしまうというのは、本当にすごいことですね。

## 利用について

ソースコード(とインストラクションカード)の利用(改変や分析など)はご自由にどうぞ。私はAIの生成物に対して著作権の存在を認めない立場です。2026/09/09現在においては日本国での判例は存在していませんが、私の考えではそうなっています。

その一方で、生成に利用したプロンプトに関しては日本国著作権法(昭和四十五年法律第四十八号)のもとご利用ください。
